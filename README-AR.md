# WE Schools — نسخة تجريبية بلوحة إدارة بسيطة

## التشغيل
1. ضع مجلد `we-schools` داخل `htdocs` في XAMPP.
2. شغّل Apache.
3. افتح `http://localhost/we-schools/`.
4. اضغط Continue ثم Admin؛ ستظهر صفحة تسجيل الدخول كل مرة تختار فيها Admin.
5. كلمة مرور الإدارة التجريبية: `WAdmin`.

## الموجود في النسخة
- صفحة الطالب نفسها لاختيار الصف والفصل واليوم وعرض الجدول.
- عند دخول الأدمن تظهر أزرار Add session وEdit وDelete داخل جدول الحصص نفسه.
- نموذج الحصة يحتوي على حقول كتابة حرة للمادة والـ Type (مثل class أو break أو lab)، ووقت البداية والنهاية، واسم المدرس، ومحتوى الدرس.
- أسماء المدرسين والمواد الحالية بيانات تجريبية. اسم البريك يظهر Break فقط.
- تواريخ الأحد إلى الخميس تُحسب تلقائيًا للأسبوع الحالي.

## ملاحظة مهمة قبل تسليم الباك إند
تعديلات Add/Edit/Delete في هذه النسخة التجريبية تُحفظ في الملف `data/demo_sessions.json` داخل المشروع، وليست مربوطة بقاعدة بيانات بعد. الكود التجريبي منفصل في `admin/insert.php` و`admin/edit.php` و`admin/delete.php`، مع أدوات مشتركة في `admin/common.php`. تأكد أن مجلد `data` قابل للكتابة بواسطة PHP.
كلمة المرور `WAdmin` مؤقتة للتجربة فقط وليست حماية مناسبة لموقع منشور على الإنترنت.
